# AI 论文学术档案库（研究领域聚焦）

一个单文件、零外部依赖的静态学术档案库，聚焦以下研究方向：

- AI 认知算法
- LLM
- AI Agent
- 世界模型
- 虚拟仿真社会
- AI 心理学

数据由 AI HOT 公开精选池按领域检索整理，每篇论文的摘要由本机 Ollama/Qwen 本地模型翻译为中文，点击卡片「查看中文翻译」即可在手机/桌面端阅读中文译文。

## 文件
- `index.html`：生成的单文件档案库（唯一需要托管的产物）。
